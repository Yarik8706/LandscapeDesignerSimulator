# Landscape Designer Simulator

## Описание проекта

**Landscape Designer Simulator** — это игра-симулятор ландшафтного дизайна, разработанная на Unity. Проект представляет собой стратегическую игру с элементами градостроительства, где игрок проектирует и строит ландшафтные зоны, управляя бюджетом, временем строительства и качественными характеристиками проекта (эстетика и функциональность). Игра включает систему диалогов с AI-ассистентом для помощи в планировании проектов и интеграцию с облачным бэкендом для обработки игровых событий.

## Реализованные системы

### 🏗️ Система строительства (Build System)
- **Размещение элементов** — система установки строительных элементов на игровую сетку с проверкой ограничений
- **Категории элементов** — поддержка различных категорий (Embankment, Decoration)
- **Валидация размещения** — проверка совместимости элементов, типов поверхности и климатических условий
- **Система подсыпки** — механика укрепления почвы через элементы категории Embankment
- **Terraform система** — поддержка оверлейных элементов (например, мосты над водой)

### 📊 Система расчёта проекта (Project Calculator)
- **Динамический подсчёт метрик** — автоматический расчёт стоимости, времени строительства, эстетики и функциональности
- **Учёт поверхностей** — различная стоимость замены и наложения элементов на разные типы грунта
- **Агрегация данных** — сбор данных со всех ячеек текущего уровня

### 🗺️ Система уровней и карт
- **Сеточная система (Grid-based)** — игровое поле разделено на ячейки (Cell)
- **Типы поверхностей** — поддержка различных типов местности (Pond, Swamp, Forest, Steppe, Mountain)
- **Характеристики почвы** — система прочности почвы (SoilStrength) и типов грунта (DirtType)
- **Управление уровнями** — система выбора и переключения между уровнями

### 💬 Система диалогов с AI
- **Интеграция с Next.js бэкендом** — прямые HTTP-запросы к серверу
- **Чат-сервис** — система обмена сообщениями с AI-ассистентом для консультаций по проектированию
- **Режим отладки** — поддержка тестирования в редакторе Unity
- **Система повторных попыток** — обработка ошибок сети с автоматическими повторами

### 🎨 Система визуализации
- **ScriptableObject архитектура** — данные элементов хранятся в ScriptableObject ассетах
- **Эффекты создания/разрушения** — визуальные эффекты при установке и удалении элементов
- **Сортировка по слоям** — корректное отображение элементов в зависимости от позиции

### 🎵 Аудио система
- **Звуковые эффекты** — звуки установки и разрушения элементов
- **Фоновая музыка** — управление музыкальным сопровождением через GameData
- **AudioManager** — централизованное управление всеми звуками

### 🎮 Игровая логика
- **Система этапов строительства** — различные стадии игры (Creating, Building, FixMistakes)
- **Механика поломок** — система разрушения элементов с возвратом половины стоимости
- **Контекстное меню ячеек** — интерактивное управление элементами на карте
- **Система бонусов смежности** — бонусы за размещение элементов рядом друг с другом

## Технологический стек

### Основные технологии

#### Game Engine & Framework
- **Unity 2022.3.47f1** — игровой движок
- **C# (.NET)** — основной язык программирования
- **Universal Render Pipeline (URP) 14.0.11** — современный рендер-пайплайн Unity
- **TextMeshPro 3.0.7** — продвинутая система рендеринга текста
- **Git** — система контроля версий

#### Backend & Networking
- **Next.js Backend** — серверная часть на базе Next.js (развёрнута на Vercel)
- **HTTP/REST API** — прямое взаимодействие с бэкендом через UnityWebRequest
- **JSON сериализация** — использование JsonUtility для обмена данными

#### Development Tools
- **Rider IDE 3.0.31** — интеграция с JetBrains Rider

#### Architecture Patterns
- **ScriptableObject Pattern** — для хранения данных игровых элементов
- **Singleton Pattern** — для глобальных менеджеров (BuildSystem, ProjectCalculator, AudioManager)
- **Observer Pattern** — для событий инициализации и обновления состояния
- **Data-Driven Design** — конфигурация через ScriptableObject ассеты
